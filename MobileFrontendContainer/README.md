# Notes App Mobile (Minimal Scaffold)

A minimal Flutter app used to resolve container startup issues. It provides:
- Proper Flutter project structure
- lib/main.dart entrypoint
- Basic home screen with a placeholder FAB

## Run
```bash
cd MobileFrontendContainer
flutter pub get
flutter run
```

## What you get
- Home screen titled "Notes App"
- Empty state in the center
- FloatingActionButton (+) that shows a SnackBar "Coming soon"
